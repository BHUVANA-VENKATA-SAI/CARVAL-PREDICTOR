About CARVAL-PREDICTOR

CARVAL-PREDICTOR is a machine learning based application designed to estimate the resale price of used cars. The system analyzes vehicle details such as company, model, manufacturing year, kilometers driven, fuel type, seller type and transmission to generate an estimated selling price.
